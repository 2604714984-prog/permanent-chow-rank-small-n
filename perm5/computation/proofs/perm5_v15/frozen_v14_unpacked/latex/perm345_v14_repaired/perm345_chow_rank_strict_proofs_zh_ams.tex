\begin{abstract}
本文在特征零域上确定三、四、五阶永久多项式的 Chow 秩，依次为
\(4,8,16\)。三阶结论由 \(C_{1,2}\) 与 Koszul 展平的手工核计算得到；
四阶结论使用二次导数空间、低秩二次型分类及一个精确有理数图表子式。
五阶部分先用拆项引理把任意至多十五项表达式化为 fixed-six 加九项
余式，从而绕开旧 lower--15 计算层；再从 \(C_{3,2}\) 出发，以
Petersen 乘积影子和双商不等式把反设缩为 58 个整数状态；全局图界、
父集计数和相对 Grassmann 论证
排除非临界状态。九个 \(d=10\) 状态由同时 elementary shifting、
层缺陷恒等式给出的十四个 shifted 终点、六边父集公式及
Petersen 纤维轮廓不等式缩到三个局部模型；旧的 \(1405\) 轮廓遍历、
七行纤维选择表、四十九项可见影子表、四十二个方向记录及一步 witness
forest 已从证明依赖删除；十四个异常逆像的最小值表也已由三个移动
模式的显式父集结构替代；全局小图层的十二项 crossing 边际表则由
三段割代价的闭式密度定理替代，无 crossing 的 square 轨道表则由
二点压缩、Kruskal--Katona 包络及四种 Ferrers 闭式度界替代。三个
模型分别由长度二局部环、十四权统一结构不等式，
以及形式列刚性、Boolean Fourier 刚性和 \(2215>2205\) 的特征零 Koszul
估计排除。orbit--1 还存在共同包络终端 \(W_M\)；本文以同行全阶赋值
定理排除它。十五权终端的完备性则由一个五顶点图闭式处理：相对延拓
等于基底三角形、含外点三角形、三个指定四圈及平方顶点权之和；十类
非零 Möbius 项族和基底图 \(K_4\) 的八行表证明临界值三十六只在三个
长度二终端及 \(W_M\) 取得。因而五阶 lower--16 不再依赖
\(\binom{15}{10}=3003\) 项有理数穷尽、SAT/DRAT、Gröbner 基或历史
10GB 文件。其一维交旗标定理使用闭关联与 Borel 不动点把任意特征零
旗标退化到两类坐标端点，再以一个独立重建的严格模三证书穷尽
\(886{,}464\) 个端点；该证书是逻辑前提。附录给出其完整计算规范、
源码、输出哈希以及其余组合表的独立核查和 fail-closed 重放协议。
\end{abstract}

\section{引言与证明边界}

令 \(V_n=\Span\{x_{ij}:0\le i,j<n\}\)，并令
\[
 \perm_n=\sum_{\sigma\in S_n}\prod_{i=0}^{n-1}x_{i,\sigma(i)}
 \in\Sym^nV_n.
\]
一个 Chow 项是 \(n\) 个线性形式的乘积；Chow 秩是表示给定齐次多项式
所需 Chow 项的最少数目。全文区分：纯数学证明、精确整数/有理数证书、
严格模素数非零子式、有限穷举和随机诊断。随机诊断不承担任何定理结论；
有限域等号不自动提升为特征零等号；缺失文件、哈希不符、状态遗漏或
非零子式验证失败均使相应计算引理失败。

\begin{theorem}[主定理]\label{thm:main}
在任意特征零域上，
\[
 \ChowRank(\perm_3)=4,\qquad
 \ChowRank(\perm_4)=8,\qquad
 \ChowRank(\perm_5)=16.
\]
其中 \(n=3\) 为手工证明，\(n=4\) 使用精确有理数证书，\(n=5\)
由特征零代数几何、有限图论、正文完整列出的整数表和一个精确模三
端点证书证明。故五阶结论属于计算机辅助证明，而不是“纯组合”或
“program-free”证明。
\end{theorem}
