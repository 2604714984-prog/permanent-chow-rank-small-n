## 4. 特殊纤维长度恰为二

\[
u=\sum_{0\le i\le j\le3}c_{ij}x_{0i}x_{0j}
 +\sum_{i=0}^3a_i x_{0i}y+a_4y^2

按上述互异权比较，依次得到

\[

长度恰为二。

## 5. 严格的相对次数引理

原文“拟有限态射取有限邻域后直接用 Nakayama”的说法应替换成下面的完成局部环版本。

**引理。** 设 \(\pi:X\to B\) 为有限型态射，(x\in X_b) 是特殊纤维的孤立点，且
\(\operatorname{length}\mathcal O_{X_b,x}=\ell\)。令

\[
R=\widehat{\mathcal O}_{B,b},\qquad
A=\widehat{\mathcal O}_{X,x}.
\]

则 (A) 是有限 (R)-模，并可由 (ell) 个 (R)-生成元生成。因而任意 DVR 弧及所有专门化到 (x) 的提升，在几何泛纤维中至多给出 (ell) 个互异点。

**证明。** (A/\mathfrak m_RA\) 是长度 (ell) 的 Artin 局部环。取其一组基的提升
(a_1,\ldots,a_\ell\)。对任意 (a\in A)，先模
\(\mathfrak m_R A\) 用这些提升表示；再对余项重复。完备性使所得系数在 (R) 中收敛，故
(A=\sum Ra_i\)。DVR 基变换并完成后，所得代数仍由 (ell) 个元素生成；张量到分式域后的向量空间维数至多 (ell)，故其几何点数也至多 (ell)。证毕。

对当前关联胚取 (ell=2)，可得：所有专门化到同一个 ((L_0,Z_0)) 的共同
((S,T,W))-提升，泛纤维至多有两个几何点。这一论证允许 base parameter 与 vertical parameter 的乘积项，因而没有 relative--Rees 缺口。
