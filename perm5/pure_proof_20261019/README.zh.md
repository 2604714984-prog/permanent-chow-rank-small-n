# perm5 无计算证明：最终版本说明

日期：2026-10-19。主张是特征零上的**普通 Chow rank 等于 16**，不涉及 border Chow rank。

本版的数学论证已完整写入 `main.tex`。证明程序可以全部删除，不影响正文的逻辑完整性。程序保留下来，仅用于发现推导或实现错误，不作为任何引理的前提。

## 先纠正版本对应关系

这次改写的是 `submissions/20261016-r2/perm5/main.tex` 的**短证明**，不是此前聊天介绍的“固定六项、58 个状态、终端轨道”旧路线。那个旧路线属于历史版本。

当前证明最重要的结构是：先控制每个五次乘积在新变量方向上的导数贡献，再把所有项的贡献相加，与两个导数像空间的总维数限制比较。整个下界论证不需要列出 58 个状态。

## 1. 假设有 N 项分解，记录三个量

设

\[
\operatorname{perm}_5=T_1+\cdots+T_N.
\]

对每项，令 \(F_i\) 是三次求导后得到的二次式空间，\(U_i\) 是二次求导后得到的三次式空间。它们是**真实的导数像空间**，不是形式上任取因子乘积构成的大空间。

两者维数相等，记为 \(u_i\le10\)。定义

\[
\Delta=\sum_i(10-u_i),
\]

它表示各项导数维数距离最大值 10 的总缺额。

perm5 自身的二次、三次导数空间各有 100 维。记所有项的二次像空间之和为 \(F\)，三次像空间之和为 \(U\)，并写成

\[
\dim F=100+h_2,\qquad\dim U=100+h_3.
\]

由于 permanent 的导数像空间包含在对应的项像空间之和中，\(h_2,h_3\) 均非负。

## 2. 第一条全局不等式：额外空间不能太大

利用一对互为转置的矩形 catalecticant，正文直接证明

\[
 h_2+h_3\le10N-100-\Delta.
\]

这里没有假设不同项的导数空间彼此独立。恰恰相反，矩形像空间不等式同时控制列像和转置像，把可能的交叠包含在内。

## 3. 第二条全局不等式：新变量方向必须贡献足够多的信息

逐项加入因子张成的变量空间。第 \(i\) 项新增 \(d_i\) 个独立变量方向，总计为

\[
\sum_i d_i=25.
\]

这不是额外假设：perm5 的二次导数再求导可以张成全部 25 个变量，所以这些项的因子空间总和必须包含整个变量空间。

局部核心引理是

\[
\operatorname{rank}\beta_i+\frac{10-u_i}{2}\ge2d_i.
\]

\(\beta_i\) 是把该项的三次式求一阶导数，再只保留新变量方向和模掉 permanent 已有二次导数后的信息。证明对依赖因子、重复因子以及任意非坐标商空间都成立。

通过变量空间的逐步过滤相加，得到

\[
 h_3\ge50-\frac{\Delta}{2}.
\]

这里也没有把各项的未投影像空间当成互相独立。新方向投影消掉前面项的像，才允许累加这些下界。

## 4. 最终矛盾只有几行

合并两条不等式：

\[
\boxed{h_2+\frac{\Delta}{2}\le10N-150.}
\]

若 \(N<15\)，右边为负，立即矛盾。若 \(N=15\)，非负性迫使

\[
h_2=0,\qquad\Delta=0.
\]

第一条意味着所有项的二次像空间之和恰好就是 permanent 的二次导数空间。第二条意味着每个 \(F_i\) 都有 10 维。

然而，每项最多依赖五个线性变量。正文已经证明：permanent 的二次导数空间与任意至多五维变量空间的二次式空间，交集至多一维。因此出现

\[
10=\dim F_i\le1,
\]

矛盾。不超过 15 项的分解被全部排除。Glynn 恒等式给出 16 项上界，且恒等式由正负号抵消直接证明。

## 5. 计算具体是怎样被去掉的？

**独立五因子情形：用三元组公式，不枚举 352 种状态。**

把变量商空间的核退化到一个坐标子集 \(B\)，记 \(b=|B|=5-d\)。可能被商掉的二次方向是零空间，或一个坐标边 \(e\)。每个三元组的极化列都有独占的支撑。被消掉的列只有两类：三元组完全落在 \(B\) 内；或只有一个顶点在 \(B\) 外，而另外两个顶点正好是 \(e\subset B\)。因此秩等于

\[
10-\binom b3-d\,\mathbf1_{\{R\ne0,\ e\subset B\}}.
\]

当 \(b\ge2\)，最坏下界减去 \(2d\) 后因式分解为

\[
\frac{(5-b)(b^2+2b-6)}6\ge0.
\]

当 \(b=0,1\)，秩为 10。这就给出了所有情形的统一证明。

**低维因子空间：用二次因子数量公式，不枚举正整数分拆。**

把五个线性因子的乘积退化成使用全部 \(\ell\) 个变量的单项式，指数为 \(\alpha_i\ge1\)，总和为 5。其二次因子数是

\[
\binom{\ell}{2}+\#\{i:\alpha_i\ge2\}.
\]

当 \(\ell\le4\) 时，至少一个指数不小于二。因此直接得到

\[
u\ge\binom{\ell}{2}+1.
\]

**四维因子空间：只证明需要的导数事实，不求四个矩阵的完整秩。**

归一化后的项为

\[
T_s=x_1x_2x_3x_4(x_1+\cdots+x_s),\qquad s=1,2,3,4.
\]

前两种情形，只用若干零导数以及

\[
\partial_1\partial_2T_2=\partial_1^2T_2+\partial_2^2T_2
\]

就有 \(u\le7\)，再用实际出现的两个平方自由三次式，证明任何非零方向至少贡献一个非零商方向。

后两种情形，只用

\[
\partial_j^2T_s=2\prod_{i\ne j}x_i\qquad(j\le s)
\]

以及两三个三次式导数的独立性，得到需要的秩下界。**最后两种情形的精确秩 9、10，已不再是正文需要证明或引用的事实。**

剩余低维情形用一个代数不等式统一处理，也不再做区间逐值最小化。

## 6. 审计关注点与实际检查

退化论证明确区分：秩在特殊化中只能下降，核和交集的维数可以增加。独立五因子引理在退化时可能把原来的秩四二次型变成秩二单项式，但该引理证明的是对任意零维或一维二次子空间都成立的更强版本，因此没有偷用极限处的秩四条件。

可选的独立程序已经实际检查了 352 个坐标符号、399 个精确局部商空间例子、252 个小补空间核恒等式，以及正规形导数、prolongation 和 Glynn 展开。在真正的 16 项 Glynn 分解上，还得到 \((h_2,h_3,\Delta)=(10,50,0)\)，两条全局界均取等号。这些是交叉检查，不替代正文中的全参数证明。
