## Package and processor

Each ZIP expands directly to `main.tex` plus `anc/`. Choose `main.tex` as the
main file and **PDFLaTeX** as the processor. All required manuscript content
and bibliography entries are in `main.tex`; there are no external figures,
custom style files, font files, BibTeX databases or shell-escape requirements.
Keep the ancillary directory intact. Do not rename it or flatten its files.

The full source download includes the ancillary code. A reader can run
`python -B anc/verify_submission.py` with Python 3.11+ and its standard library.
The exact computational subset is checked against the original expected
certificate hashes, including the unchanged full original manifest. Historical
manuscripts omitted from that subset remain available in the repository.
