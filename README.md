# Exact Chow Ranks of Two Small Permanents

The results are published as two independent proof packages:

- [`perm3/`](perm3/):
  \(\operatorname{ChowRank}(\operatorname{perm}_3)=4\).
- [`perm4/`](perm4/):
  \(\operatorname{ChowRank}(\operatorname{perm}_4)=8\).

Each directory contains its own manuscript PDF, complete AMS LaTeX source,
exact certificates, replay entry point, and reproduction instructions. Neither
proof package depends on files from the other.
